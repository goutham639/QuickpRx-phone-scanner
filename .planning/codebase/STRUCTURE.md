## Directory Purposes

**src/**
- Purpose: All application source code
- Contains: Components, hooks, types, entry points
- Key files: `main.tsx`, `App.tsx`, `index.css`
- Subdirectories: `components/`, `hooks/`, `types/`

**src/components/**
- Purpose: React UI components
- Contains: `.tsx` files for presentational components
- Key files: `Scanner.tsx`, `PairCodeInput.tsx`, `ScanFeedback.tsx`
- Subdirectories: None (flat structure)

**src/hooks/**
- Purpose: Custom React hooks with business logic
- Contains: `.ts` files for hooks
- Key files: `useScannerSession.ts`, `useBarcodeScanner.ts`
- Subdirectories: None

**src/types/**
- Purpose: Shared TypeScript type definitions
- Contains: Type exports
- Key files: `index.ts`
- Subdirectories: None

**public/**
- Purpose: Static assets served directly
- Contains: PWA icons
- Key files: `icon-192.png`, `icon-512.png`
- Subdirectories: None

## Naming Conventions

**Files:**
- Components: PascalCase (`Scanner.tsx`, `PairCodeInput.tsx`)
- Hooks: camelCase with `use` prefix (`useScannerSession.ts`)
- Types: camelCase (`index.ts` in types folder)
- Config: kebab-case or standard names (`vite.config.ts`, `package.json`)

**Directories:**
- lowercase plural (`components/`, `hooks/`, `types/`)
- No nested component directories

**Special Patterns:**
- `index.ts` for barrel exports in `types/`
- No barrel files in `components/` or `hooks/`

## Where to Add New Code

**New Feature:**
- Primary code: `src/components/` for UI, `src/hooks/` for logic
- Tests: `src/__tests__/` (would need to create)
- Config if needed: Root directory

**New Component:**
- Implementation: `src/components/NewComponent.tsx`
- Types: Add to `src/types/index.ts` or inline
- Tests: `src/components/__tests__/NewComponent.test.tsx`

**New Hook:**
- Implementation: `src/hooks/useNewHook.ts`
- Types: Add to `src/types/index.ts` or inline
- Tests: `src/hooks/__tests__/useNewHook.test.ts`

**New API Integration:**
- Implementation: Extend `src/hooks/useScannerSession.ts` or create new hook
- Types: Add message/response types to `src/types/index.ts`

**Utilities:**
- Shared helpers: Create `src/utils/` directory
- Type definitions: `src/types/`

## Special Directories

**dist/**
- Purpose: Production build output
- Source: Generated by `npm run build`
- Committed: No (gitignored)

**public/**
- Purpose: Static assets copied directly to build
- Source: Manually added PWA icons
- Committed: Yes

**node_modules/**
- Purpose: npm dependencies
- Source: Generated by `npm install`
- Committed: No (gitignored)
