  <action>
Create new hook following useBarcodeScanner.ts patterns:

**State:**
- status: 'idle' | 'starting' | 'active' | 'capturing' | 'error'
- error: string | null

**Refs:**
- videoRef: RefObject<HTMLVideoElement | null>
- streamRef: useRef<MediaStream | null>
- canvasRef: useRef<HTMLCanvasElement | null> (for capture)

**Methods:**
1. `start(): Promise<void>`
   - Request camera with getUserMedia({ video: { facingMode: 'environment', width: { ideal: 1920 }, height: { ideal: 1080 } }, audio: false })
   - Higher resolution than barcode scanner (1920x1080 vs 1280x720) for OCR quality
   - Set videoRef.current.srcObject = stream
   - Call video.play()
   - Handle permission errors with user-friendly messages
   - Set status 'active' on success

2. `stop(): void`
   - Stop all stream tracks
   - Clear video srcObject
   - Set status 'idle'

3. `capture(): Promise<Blob | null>`
   - If no stream, return null
   - Set status 'capturing'
   - Create canvas if not exists (lazy init)
   - Set canvas dimensions to video.videoWidth x video.videoHeight
   - Draw video frame to canvas
   - Return canvas.toBlob() as Promise with type 'image/jpeg', quality 0.85
   - Set status back to 'active' after capture
   - Return blob

**Return interface:**
Export `UseLabelCapture` interface with all state and methods.

**Cleanup:**
- useEffect cleanup to stop stream on unmount

**Config:**
- Do NOT use environment config (unlike API hooks) - this is purely client-side

The capture() method needs a Promise wrapper for canvas.toBlob() since toBlob uses a callback.

Add helper function inside the hook file (not exported):

```typescript
function canvasToBlob(canvas: HTMLCanvasElement, type: string, quality: number): Promise<Blob | null> {
  return new Promise((resolve) => {
    canvas.toBlob((blob) => resolve(blob), type, quality);
  });
}
```

Update capture() to use this helper.
