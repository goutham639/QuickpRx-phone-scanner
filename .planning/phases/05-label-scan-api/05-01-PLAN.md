<task type="auto">
  <name>Task 2: Create useLabelScanSession hook</name>
  <files>src/hooks/useLabelScanSession.ts</files>
  <action>
Create new hook following useScannerSession.ts patterns:

**State:**
- status: LabelScanSessionStatus
- sessionId: string | null
- token: string | null (stored in ref, needed for upload auth)
- error: string | null
- uploadCount: number

**Methods:**
1. `join(code: string): Promise<boolean>`
   - POST to `/v1/label-scan/sessions/join` with { pair_code: code }
   - Store session_id, token on success
   - Handle 404 (invalid code), 400 (missing code) errors with user-friendly messages
   - Set status: 'joining' during request, 'active' on success, 'error' on failure

2. `upload(imageBlob: Blob): Promise<{ success: boolean; scanItemId?: string; error?: string }>`
   - POST to `/v1/label-scan/sessions/{sessionId}/upload`
   - Authorization: Bearer {token}
   - Content-Type: multipart/form-data
   - Form field: 'image'
   - Set status: 'uploading' during request, 'active' on success
   - Handle 401 (expired token), 403 (token mismatch), 400 (rate limit, no image) errors
   - Return scan_item.pk on success for tracking

3. `disconnect(): void`
   - Reset all state to initial values
   - Clear token ref

**Config:**
- Use existing API_URL pattern: `import.meta.env.VITE_API_URL || 'https://api.quickprx.com'`

**Return interface:**
Export `UseLabelScanSession` interface with all state and methods.

**Error handling:**
- Try-catch at async boundaries
- Extract error message from API response (check response.message, response.error)
- Fallback to generic user-friendly message
