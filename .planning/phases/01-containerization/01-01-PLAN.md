<task type="auto">
  <name>Task 2: Create nginx.conf for PWA</name>
  <files>nginx.conf</files>
  <action>
Create nginx.conf with PWA-optimized cache headers (from RESEARCH.md):

1. Listen on port 80, serve from /usr/share/nginx/html
2. Enable gzip for text, css, js, json, manifest
3. Cache headers by file type:
   - /assets/* → immutable, 1 year cache (hashed by Vite)
   - /workbox-* → immutable, 1 year cache
   - /sw.js → no-cache, no-store, must-revalidate (critical for updates)
   - /manifest.webmanifest → max-age=0, must-revalidate
   - Everything else → max-age=0, must-revalidate, try_files to index.html (SPA routing)

CRITICAL: Do NOT cache sw.js or index.html with long TTLs - this breaks PWA updates.
  </action>
  <verify>cat nginx.conf shows correct cache headers for /assets/, /workbox-, /sw.js, and / locations</verify>
  <done>nginx.conf has gzip enabled, correct cache headers for PWA, and try_files for SPA routing</done>
</task>

<task type="auto">
  <name>Task 3: Create multi-stage Dockerfile</name>
  <files>Dockerfile</files>
  <action>
Create multi-stage Dockerfile:

Stage 1 (build):
- FROM node:20-alpine AS build
- WORKDIR /app
- COPY package*.json ./
- RUN npm ci (deterministic install)
- COPY . .
- RUN npm run build

Stage 2 (production):
- FROM nginx:stable-alpine
- COPY nginx.conf /etc/nginx/conf.d/default.conf
- COPY --from=build /app/dist /usr/share/nginx/html
- EXPOSE 80
- CMD ["nginx", "-g", "daemon off;"]

This produces a ~25MB image (nginx:alpine + static files) instead of ~500MB+ with Node.
  </action>
  <verify>docker build -t phone-scanner:test . succeeds without errors</verify>
  <done>Docker image builds successfully, uses multi-stage pattern, final image is under 50MB</done>
</task>
