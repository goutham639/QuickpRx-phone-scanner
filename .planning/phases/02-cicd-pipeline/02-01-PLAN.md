   - Calculate tags: latest, prod, prod-{short-sha}
   - Build and push with docker/build-push-action@v6

2. **deploy**:
   - Needs: build-and-push
   - SSH to droplet (secrets.DROPLET_IP, DROPLET_USER, SSH_PRIVATE_KEY)
   - Login to DOCR on droplet
   - docker compose pull phone-scanner
   - docker compose up -d phone-scanner
   - docker image prune -f

Environment: Prod (same as PillRoute)
Use GHA cache for faster builds.
