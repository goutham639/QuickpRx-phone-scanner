  <name>Task 1: Create LabelScanner component</name>
  <files>src/components/LabelScanner.tsx</files>
  <action>
Create LabelScanner component integrating useLabelScanSession and useLabelCapture hooks.

Component structure (3 states based on sessionId):
1. **Pair code entry** (no sessionId): Reuse PairCodeInput-like UI with onJoin calling useLabelScanSession.join()
2. **Camera active** (has sessionId): Full-screen camera with capture button at bottom
3. **Uploading** (after capture): Show upload progress/success feedback

Props interface:
```typescript
interface LabelScannerProps {
  onDisconnect: () => void;
  onModeSwitch: () => void;  // For switching to barcode mode (Plan 02)
}
```

Implementation details:
- Auto-start camera when session joined (like Scanner.tsx pattern)
- Capture button triggers: capture() → upload(blob) → show feedback
- Upload feedback: optimistic checkmark overlay (reuse ScanFeedback pattern), error toast like Scanner.tsx
- Header bar: connection status (green/red dot), upload count badge, disconnect button (matches Scanner.tsx)
- Bottom bar: "Mode: Label Scan" indicator, capture button (large, centered), placeholder for mode switch

UI styling: Follow Scanner.tsx patterns exactly (bg-black, safe-top/safe-bottom, backdrop-blur header)

Error handling:
- Join errors: Display below code input (like PairCodeInput.tsx)
- Camera errors: Full-screen error state with retry button (like Scanner.tsx)
- Upload errors: Toast at top, auto-dismiss after 3s (like scanError in Scanner.tsx)
